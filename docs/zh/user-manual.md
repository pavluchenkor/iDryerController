### 设备用途和一般信息

该设备用于干燥和储存3D打印用的耗材。设备可以作为KIT套件或已组装的形式提供。已组装的设备已预先配置，不需要任何特殊设置。

### 设备控制

#### 打开和关闭设备

通过前面板上的开关来打开和关闭设备。打开时会显示设备的当前固件版本，如果腔室内温度超过40℃，风扇可能会启动。这是正常行为。关闭干燥机不需要任何预先操作。

#### 菜单

所有设备控制都通过菜单进行。菜单导航使用旋转按钮（编码器）进行。

* 顺时针旋转 - 增加数值或选择下一个菜单项
* 逆时针旋转 - 减少数值或选择上一个菜单项
* 短按 - 激活所选菜单项
* 长按 - 返回上一级菜单或停止当前运行模式（干燥或储存）

### 耗材干燥模式

将所需数量的耗材线轴装入干燥机，可选择将耗材穿过PTFE管，如果计划从干燥机中打印。在DRYING菜单中设置温度(`TEMPERATURE`)和时间（以分钟为单位）(`TIME`)。选择`START`启动干燥模式。如需要，可通过长按编码器来停止干燥。

在干燥模式下，显示屏定期在称重数据和干燥参数之间切换：

* 菜单顶行显示目标温度和剩余时间
* `AIR` - 腔室内的空气温度
* `HEATER` - 加热元件温度
* `HUMIDITY` - 腔室内的相对湿度

干燥模式下设备的工作算法：

1. 以100%风扇速度加热至目标温度
2. 降低风扇速度，在指定时间内保持温度
3. 根据设置进入储存模式

### 耗材储存模式

耗材储存模式可通过STORAGE菜单手动启动，或在干燥过程完成后自动启动。在此模式下，设备保持腔室内的目标相对湿度，这样任何时刻都可以开始打印而无需预先干燥耗材。在`STORAGE`菜单中设置目标相对湿度`HUMIDITY`和最大允许温度`TEMPERATURE`。选择START启动储存模式。通过长按编码器来停止储存模式。

在储存模式下，显示屏定期在称重数据和储存参数之间切换：

* 菜单顶行显示目标温度和剩余时间
* `AIR` - 腔室内的空气温度
* `HEATER` - 加热元件温度
* `HUMIDITY` - 腔室内的相对湿度

### 影响干燥的参数设置

设置位于`SETTINGS`菜单中。可以修改空气流量、腔室温度和加热元件温度之间的差异、风门和PID设置。修改参数后，必须通过调用`SETTINGS -> SAVE`来保存它们

#### 风扇设置

`AIRFLOW`  
设置达到工作温度后风扇的工作百分比，以降低设备噪音。推荐值 - 不低于70。

#### 温度差异设置

`DELTA`  
设置加热元件温度和干燥机腔室温度之间目标差异的值。推荐值 - 20。差异过大可能导致加热不均匀，例如耗材融化。差异过小会导致加热时间过长。

#### 风门伺服驱动设置

`SETTINGS -> SERVO` 
干燥机配备了一个带伺服驱动的通风风门，可以让潮湿的空气从干燥机腔室逸出。工作时，干燥机定期打开风门进行通风，然后关闭。

* `CLOSED` - 风门关闭时间（分钟）
* `OPEN` - 风门打开时间（分钟）
* `CORNER` - 风门打开的角度（推荐值 - 85）
* `TEST` - 打开/关闭风门进行测试

#### PID控制器设置

`PID`  
PID（比例-积分-微分）控制器设置。本部分适用于高级用户，通常不需要调整

* `kP`  
  比例分量增益系数
* `kI`  
  积分分量增益系数
* `kD`  
  微分分量增益系数
* `AUTOPID`  
  自动PID调整

### 称重设置

#### 称重校准

称重设置对每个线轴分别进行。为了校准称重，请准备一个恰好1千克的重物，该重物应能稳定地放在线轴平台上。

进入`SCALE -> SPOOLX -> SET`菜单。当显示屏指示时，清空称重平台上的所有物品。然后当显示屏显示相应信息时，将准备好的1千克重物放在平台上。

#### 称重去皮

如果您使用相同线轴上的耗材，设置"去皮"可能会很方便 - 空线轴的质量，这样称重器就能显示剩余耗材的净质量。此操作不能替代称重校准。

将空线轴放在平台上，等待显示其重量，然后在相应的菜单`SCALE -> SPOOLX -> TARE`中设置它

### 问题和解决方案

#### 打开干燥机时显示错误信息和/或发出蜂鸣声

按一次旋转按钮进入主菜单。  
如果设备继续蜂鸣 - 通过关闭和打开重新启动。如果问题重复出现，请尽量记住错误号并将其报告给开发者。

#### 干燥机自动退出干燥模式

此问题可能是由干燥模式下风扇速度过低和相应的电源负载引起的。在`SETTINGS -> AIRFLOW`菜单中设置推荐值75或更高。如果问题仍然存在，将此值设置为100。

#### 干燥模式下风扇发出异常声音

此问题可能由干燥模式下风扇速度过低引起。在`SETTINGS -> AIRFLOW`菜单中设置推荐值75或更高

#### 称重显示不适当的数值

检查称重平台与干燥机底部的紧固，如果紧固不紧，用十字螺丝刀拧紧。按照说明校准称重器

#### 设置未应用，尽管我修改了它们

修改SETTINGS菜单下的任何设置后，必须在`SETTINGS -> SAVE`菜单中保存它们

#### 断电后显示屏没有立即熄灭

这是正常行为
