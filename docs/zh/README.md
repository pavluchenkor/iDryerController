# 固件

通用的灯丝干燥解决方案。可以由廉价易得的零件组成，例如旧的热床加热器、闲置的风扇和散热器，机箱可以使用日用品商店的纸箱和任何隔热材料。使用的零件列表仅受您的想象力限制。

功能：
- 最高干燥温度110℃
- 在选定温度下干燥指定时间
- 调节加热器功率并精确维持干燥室内的所需空气温度
- 以指定的时间间隔对干燥室进行通风
- 显示空气温度、加热元件温度、湿度
- 干燥完成后进入存储模式，并以低热量无限期存储
- 以选定的温度存储
- 达到设定湿度时节省电力，根据HUMIDITY_HYSTERESIS参数启用/禁用干燥
- 提供常用塑料的预设
- 自动PID调谐
- 称重灯丝线轴并在屏幕上显示塑料剩余量
- 在打印机主板的灯丝传感器输入上产生高电平信号

硬件特点：
- 可控制几乎任何24V/220V加热元件
- PWM控制干燥室风扇
- 24V(也可12V)工作版本，至4.3版本
- 220V工作版本
- 使用廉价的中国称重模块获得相当准确的线轴重量结果

PCB设计托管在[jlcpcb.com](https://oshwlab.com/svet_team/idryer)

固件特点：
- 固件文件包含所有可能的变体，固件配置通过编辑configuration.h文件进行
- Arduino引导加载程序固件/不是最安全的东西，尽管有大量检查和保护
  - 从v0.5.*开始，支持已停止，功能未经测试，固件中的所有引用都是遗留物
- MiniCore内核固件
  - 运行看门狗定时器/在程序故障时将重启固件
  - 俄语和英语语言
  - PID调节
  - 干燥和存储模式
  - 风扇PWM频率选择支持
  - 风扇最优频率测试
  - 支持HX711 ADC上多达4个称重模块
  - 以每秒10和80次的频率轮询称重
  - 在屏幕上显示线轴重量
  - 在菜单中输入皮重
  - 灯丝末端报警：视觉、声音、灯丝传感器输出
  - [伺服驱动支持](https://t.me/iDryer/361)用于定期干燥室通风
  - 自定义预设名称
  - 扩展菜单和功能
  - 固件安全性
