# 韌體

通用的燈絲乾燥解決方案。可以從便宜且易取得的零件組裝，例如舊熱床加熱器、不需要的風扇和散熱片，以及來自超市的紙箱作為外殼和任何隔熱材料。使用的零件列表僅受想像力限制。

功能特性：
- 可乾燥至 110°C 的溫度
- 在選定的溫度下乾燥指定時間
- 調節加熱器功率並準確維持烘箱內的空氣溫度
- 按設定的時間間隔通風室內空氣
- 顯示空氣溫度、加熱元件溫度、濕度
- 乾燥完成後進入儲存模式，可無限期地以低溫保持
- 以選定的溫度儲存
- 達到設定濕度時節省電能，根據 HUMIDITY_HYSTERESIS 參數自動開啟/關閉乾燥
- 預設了常用的塑膠材料
- 自動調整 PID
- 稱重線軸並在屏幕上顯示塑膠剩餘量
- 在腳位上生成高電平信號，用於連接印表機主板的燈絲感應器輸入

硬體特性：
- 控制幾乎任何 24V/220V 加熱元件
- 通過 PWM 控制室內風扇
- 版本支援 24V（也可 12V）的操作，直到版本 4.3
- 版本支援 220V 操作
- 使用廉價的中國製秤重模塊獲得相當準確的線軸重量讀數

PCB 設計位於 [jlcpcb.com](https://oshwlab.com/svet_team/idryer)

韌體特性：
- 韌體檔案包含所有可能的變體，韌體配置通過編輯 configuration.h 檔案進行修改
- Arduino 引導程序韌體 / 儘管有許多檢查和保護，但不是最安全的
  - 從 v0.5.* 開始支援已終止，功能未經測試，韌體中的所有引用都是遺留物
- MiniCore 核心韌體
  - 支援看門狗計時器 / 在軟體故障時重新啟動韌體
  - 俄語和英語
  - PID 控制
  - 乾燥和儲存模式
  - 支援風扇 PWM 頻率選擇
  - 風扇最佳頻率測試
  - 在 HX711 ADC 上支援最多 4 個秤重模塊
  - 每秒採樣 10 到 80 次重量
  - 在屏幕上顯示線軸重量
  - 在菜單中輸入皮重值
  - 燈絲耗盡警報 - 視覺、聲音和燈絲感應器輸出
  - [伺服馬達支援](https://t.me/iDryer/361)用於定期室內通風
  - 自訂預設名稱
  - 擴展菜單和功能
  - 韌體安全
