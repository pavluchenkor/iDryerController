### 設備用途和一般信息

該設備用於乾燥和儲存用於3D列印的耗材。設備可作為套件(KIT)或完全組裝的形式提供。完全組裝的設備已預配置，不需要任何特殊設定。

### 設備控制

#### 打開和關閉設備

使用前面板上的開關進行打開和關閉。打開時會顯示設備的當前韌體版本。如果機艙內溫度超過40℃，可能會啟動風扇。這是正常行為。關閉乾燥器不需要任何預備操作。

#### 菜單

所有設備控制都通過菜單進行。使用旋轉按鈕(編碼器)進行菜單導航。

* 順時針轉動 - 增加數值或選擇下一個菜單項  
* 逆時針轉動 - 減少數值或選擇上一個菜單項  
* 短按 - 激活所選菜單項  
* 長按 - 返回上一個菜單或停止當前工作模式(乾燥或儲存)

### 耗材乾燥模式

將所需數量的耗材捲軸放入乾燥器，可選地將耗材穿過PTFE管，如果打算從乾燥器中進行列印。在DRYING菜單中設置溫度(`TEMPERATURE`)和時間(以分鐘為單位的`TIME`)。通過選擇`START`開始乾燥模式。如需要，通過長按編碼器停止乾燥。

在乾燥模式中，顯示屏定期在體重讀數和乾燥參數之間切換:

* 菜單上方一行顯示目標溫度和剩餘時間  
* `AIR` - 機艙內空氣溫度  
* `HEATER` - 加熱元件溫度  
* `HUMIDITY` - 機艙內相對濕度

乾燥模式下設備的工作算法:

1. 在風扇100%轉速下加熱到目標溫度  
2. 以降低的風扇轉速保持目標溫度指定時間  
3. 根據設置轉換到儲存模式

### 耗材儲存模式

耗材儲存模式可通過STORAGE菜單手動啟動，或在乾燥過程完成後自動啟動。在此模式下，設備將保持機艙內的目標相對濕度，允許隨時開始列印而無需提前乾燥耗材。在`STORAGE`菜單中設置目標相對濕度`HUMIDITY`和最大允許溫度`TEMPERATURE`。通過選擇START啟動儲存模式。通過長按編碼器停止儲存模式。

在儲存模式中，顯示屏定期在體重讀數和儲存參數之間切換:

* 菜單上方一行顯示目標溫度和剩餘時間  
* `AIR` - 機艙內空氣溫度  
* `HEATER` - 加熱元件溫度  
* `HUMIDITY` - 機艙內相對濕度

### 配置影響乾燥的參數

設置位於`SETTINGS`菜單中。可以更改空氣流量、機艙溫度與加熱元件溫度之間的差異、擋板和PID的設置。更改參數後，必須通過調用`SETTINGS -> SAVE`保存它們

#### 配置風扇

`AIRFLOW`  
設置達到工作溫度後風扇的工作百分比，以降低設備噪音。推薦值不低於70。

#### 配置溫度差

`DELTA`  
設置加熱元件溫度與乾燥機機艙溫度之間的目標差值。推薦值為20。溫差過大可能導致加熱不均勻，例如耗材熔化。溫差過小會導致加熱時間過長。

#### 調節擋板舺動機設置

`SETTINGS -> SERVO` 
乾燥器配備有由伺服馬達控制的通風擋板，允許潮濕空氣從乾燥機機艙中逸出。工作過程中，乾燥器定期打開和關閉擋板進行通風。

* `CLOSED` - 擋板關閉時間(分鐘)  
* `OPEN` - 擋板打開時間(分鐘)  
* `CORNER` - 擋板打開的角度(推薦值為85)  
* `TEST` - 打開/關閉擋板進行測試

#### PID調節器設置

`PID`  
PID(比例-積分-微分控制器)設置。本節適用於進階用戶，通常不需要調整

* `kP`  
  比例分量增益係數  
* `kI`  
  積分分量增益係數  
* `kD`  
  微分分量增益係數  
* `AUTOPID`  
  自動PID調整

### 配置體重秤

#### 體重秤校準

體重秤的配置對每個捲軸進行單獨配置。為配置體重秤，請準備一個恰好為1kg的權重，可穩定放在捲軸平台上。

進入`SCALE -> SPOOLX -> SET`菜單。當顯示屏指示時，清除體重秤平台上的所有物品。當顯示屏顯示相應消息時，將準備好的1kg權重放在平台上。

#### 體重秤去皮

如果您使用相同捲軸上的耗材，配置"去皮" - 空捲軸的質量可能很方便，這樣體重秤就可以顯示剩餘耗材的淨質量。此操作不替代體重秤校準。

將空捲軸放在平台上，等待其權重顯示，並在相應的菜單`SCALE -> SPOOLX -> TARE`中設置它

 
### 問題和解決方案

#### 打開時乾燥器顯示錯誤消息和/或蜂鳴聲

按一次旋轉按鈕退出到主菜單。   
如果設備繼續蜂鳴，通過打開-關閉重新啟動。在重複出現的情況下，嘗試記住錯誤號並報告給開發人員。

#### 乾燥器自動退出乾燥模式

此問題可能是由乾燥模式下風扇速度過度降低和相應的電源供應負載引起的。在`SETTINGS -> AIRFLOW`菜單中設置推薦值75或更高。如果問題仍然存在，將此值設置為100。

#### 在乾燥模式下風扇發出不健康的聲音

此問題可能是由乾燥模式下風扇速度過度降低引起的。在`SETTINGS -> AIRFLOW`菜單中設置推薦值75或更高

#### 體重秤顯示不適當的值

檢查體重秤平台與乾燥器底部的緊固程度，如果緊固不緊，使用十字螺絲刀擰緊。根據說明校準體重秤

#### 設置未應用，儘管我已更改它們

更改SETTINGS菜單下的任何設置後，必須在`SETTINGS -> SAVE`菜單中保存它們

#### 關閉電源後乾燥器顯示屏不會立即熄滅

此行為是正常的
